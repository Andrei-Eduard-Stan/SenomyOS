# Welcome

This is the local knowledge base for SenomyOS. Edit the Markdown files in the
`wiki/` directory and the Wiki tab will refresh while it is open.

## What Markdown becomes

| Markdown source | Wiki presentation |
| --- | --- |
| Headings | Article hierarchy |
| Lists | Scan-friendly procedures |
| Fenced code | Terminal-style code blocks |
| Pipe tables | Structured reference rows |
| Internal links | Article navigation buttons |
