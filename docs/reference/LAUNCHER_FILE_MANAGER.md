# Command Lens and file-workspace contracts

## Native entry and catalogs

Command Lens is native by default. Both Rail and keyboard entry route through the
existing shell-owned commandLens IPC and opening lease. Preserve protected reviews,
exact identities, readiness and error outcomes. A rejected/unavailable native
request must not silently start a second launcher. Rofi remains available only as
an explicitly selected legacy mode (`SENOMY_LENS_NATIVE=0`).

Applications, files, windows and allowlisted actions reuse bounded existing
catalogs. Input/query text is data, never shell interpolation. Validate returned
paths and activation IDs again. Exclude sensitive/expensive roots and keep cached
file indexes private and bounded. Refresh/load/unavailable are explicit. Application
comments can aid search without mandatory repeated result descriptions.

Result rows reserve icons and metadata separately, retain full accessible identity,
wrap meaningful commands and deliberately elide variable paths/titles. Both entry
paths use existing routing rather than new popup/controller state. Native hosting,
Win+R/Rail placement and physical focus need their own acceptance beyond an inert
body fixture.

## Persistent file workspace

Thunar remains native GTK for browsing, preview, organization and file operations.
Selecting a directory hands off to its supported reveal/open interface. Registered
custom actions use an allowlisted registry and merge without overwriting unrelated
user actions. Do not recreate file-manager operations in Lens or accept arbitrary
commands. Preserve GIO defaults, literal paths and independent app lifetime.

The scoped launcher/file-manager adapters own environment and fresh-daemon rules.
Do not mutate an already-running file-manager process or global GTK environment
just to match a source screenshot. Shared semantic roles project separately into
native QML, the explicit legacy Rasi mode and GTK; preserve authored utility art.

## Validation and deployment

Use existing native Lens/catalog/ranking/launch/error fixtures and scoped
Command Lens/Thunar contract checks. Test malformed/quoted paths, unavailable
commands, exact argv and unchanged unrelated configuration. Source and installed
regular helper copies are distinct; deployment must verify both. System/file
operations and lifecycle tests retain their normal review boundaries. Current
status and acceptance belong in [PROJECT_STATE](../PROJECT_STATE.md).
