# Boot handoff

## Scope

GRUB, Plymouth, transition to SDDM, and the matching background/brand assets under `appearance/boot/`.

## Visual contract

Project obsidian, ivory/silver, sparse violet, the Senomy mark, and a deterministic handoff sequence. Do not force Compact/Standard/Large desktop frame geometry into renderers that cannot support it faithfully.

## Interaction

Preserve boot menu legibility, fallback entries, recovery access, progress/error truth, keyboard control, and safe timeout behavior. No animation should delay boot or conceal failure.

## Acceptance

Validate common resolutions, encrypted/unlocked paths where applicable, missing assets, GRUB fallback, Plymouth failure, SDDM transition, installer deployment, update, rollback, and recovery before product claims.
