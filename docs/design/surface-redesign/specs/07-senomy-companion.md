# Senomy companion

| Contract | Specification |
| --- | --- |
| Opens | Separate Rail avatar control |
| Geometry | Right or left edge at 12x72; expanded edge ribbon and materially smaller compact tab |
| Frame | Standard expanded; Compact outer tab for compact mode |
| Motif | identity |
| Coexistence | May coexist with one primary surface; never becomes primary |

## Composition

Expanded: small move/pin/collapse/close toolbar, one bounded character-art zone, concise observer state, optional media strip, and Insights handoff. Compact: avatar plus one state line and expand affordance, not a half-height panel.

## Interaction

Preserve dock, pin, close, manual collapse/expand, timed collapse, media availability, cached image variants, and Insights deep link. Pin applies only to the current companion session.

## Acceptance

Artwork never blocks controls, never appears again inside primary surfaces, and never decodes unbounded animation assets. Toolbar targets and focus states meet desktop/touch requirements.
