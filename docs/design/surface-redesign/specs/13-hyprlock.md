# Hyprlock

| Contract | Specification |
| --- | --- |
| Renderer | Hyprlock primitives |
| Opens | Guarded lock action |
| Composition | Lower authentication rail related to SDDM |
| Frame | Simplified Large projection with Compact marks |
| Motif | identity |

## Composition

Preserve blurred live background, avatar/user, password field, prompt/error state, session/time/layout information and the current utility marks. Only interactive controls may look interactive.

## Interaction and security

Password entry and focus dominate. Never add shell actions, untrusted content, or network/system telemetry that could leak session state. Hyprlock renderer limits take precedence over decorative fidelity.

## Acceptance

Validate lock/unlock, wrong password, caps/layout indication, keyboard focus, sleep/wake, multi-monitor fallback, missing assets, and reduced motion without weakening the lock boundary.
