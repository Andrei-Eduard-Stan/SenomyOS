# Senomy Insights

| Contract | Specification |
| --- | --- |
| Opens | Rail identity/dialogue, Rail notifications, companion and deep links |
| Geometry | Bottom-centre; about 900–1000 x 740–780 on the reference display |
| Frame | Large |
| Motif | identity crest; diagnostic ticks for state changes |
| Routes | Briefing, Notifications, Timeline, Updates, Diagnostics, Console, Reports, Wiki |

## Composition

Use a shared Large header and route index, then give the reading plane route-specific structure. No character artwork is reserved in the header or content.

- Briefing is editorial and ranked.
- Notifications is a private time ledger.
- Timeline is a source/time rail.
- Updates shows trust, freshness, and manual-check boundaries.
- Diagnostics is an allowlisted runbook.
- Console is curated commands plus explicit real-terminal handoff.
- Reports is an evidence docket with privacy classification.
- Wiki is an index plus a 62–78 character reading plane.

## Interaction and safety

Preserve bounded retention, redaction, no-auto-upload, sanitized-event, fixed-command, and no-package-install boundaries. Add an approved keyboard focus model and visible source freshness.

## Acceptance

Insights reads as a first-class system briefing rather than a chatbot or generic settings panel. Narrative, evidence, actions, and provenance are visibly distinct.
