# Current-run baseline evidence

Captured from the live SenomyOS session on 2026-08-28 without reloading Eww or Hyprland and without invoking a system action.

The primary Eww routes were opened one at a time on an unused workspace, captured, and restored to the closed state. Images are cropped to the surface geometry. Runtime network names and addressing, a Bluetooth hardware address, process usernames, and retained notification prose were redacted; geometry and non-sensitive interface structure were preserved.

Current-run evidence includes:

- `rail-rest.png`
- `control-*.png` for all ten routes
- `insights-*.png` for all eight routes
- `performance-*.png` for all seven routes
- `volume-flyout.png` and `tray-flyout.png`
- `companion-expanded.png` and `companion-compact.png`
- `command-lens-apps.png`
- `thunar-file-workspace.png`
- `swaync-notification-centre.png`
- four `contact-*.png` overview sheets

SDDM, Hyprlock, and Recovery were not opened because doing so would leave, lock, or replace the active session. The audit uses their source, approved previews, and existing QA captures instead.
